My Journey into Web Development

October 1, 2026 by Anius Daniel

Learning web development has helped me better understand how the websites we use every day are created. At first, HTML seemed like a collection of different tags, but after practising with headings, paragraphs, links and images, I started to understand how each element contributes to the structure of a webpage.

CSS has made the process even more interesting because it allows me to control how the page looks. By changing colours, spacing, fonts and layout, a basic HTML document can become much more attractive and easier to read. I am especially interested in learning more about responsive design and how websites can adapt to different screen sizes.

Finding Inspiration Away from the Screen

October 3, 2026 by Anius Daniel

Spending long periods working on a computer can sometimes become tiring, so taking time away from the screen is important. Going outside, exercising or simply changing surroundings can help clear the mind and make it easier to return to work with new ideas.

I have also noticed that everyday surroundings can provide inspiration for design. Colours, shapes and the way objects are arranged can all influence the way a webpage is designed. Learning to notice these details has helped me appreciate that good design is not only about appearance but also about creating a comfortable experience for the person using it.
